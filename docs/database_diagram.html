Kỹ thuật Concurrency: Atomic Slot Locking trong MongoDB

Để chống Race Condition khi 2 người dùng cùng bấm giữ chỗ 1 khung giờ ở cùng 1 phần nghìn giây, hệ thống không dùng lệnh kiểm tra rồi lưu thông thường mà sử dụng lệnh findOneAndUpdate cấp nguyên tử của MongoDB: 

const lockedSlot = await TimeSlot.findOneAndUpdate(
  { _id: slotId, status: 'available' },
  {
    $set: {
      status: 'locked',
      locked_by: userId,
      lock_expires_at: new Date(Date.now() + 5 * 60 * 1000) // Khóa 5:00 phút
    }
  },
  { new: true }
);

if (!lockedSlot) {
  // Trả về lỗi 409 Conflict: Khung giờ vừa có người khác nhanh tay chọn trước!
}
